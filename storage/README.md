# Kulzzy Storage

This directory defines the storage structure for Kulzzy Server #01.

## Storage areas

- audio/       - Radio MP3 and audio files
- celebrants/  - Celebrant images and media
- websites/    - Kulzzy website files
- repositories/- Kulzzy Code Hub repositories
- uploads/     - General uploads
- backups/     - Server backups

Production storage will be mounted from the physical
Kulzzy server disks.
